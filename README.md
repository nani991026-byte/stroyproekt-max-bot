# СтройПроект — MAX бот

Стартовая версия строительного бота для MAX.

## Что уже умеет

- `/start`
- красивое главное меню;
- список услуг;
- простой тестовый расчёт по площади;
- запись на замер (пока в виде анкеты);
- экран договора;
- экран заявок;
- связь с менеджером.

## Важно про токен

Файл `.env` НЕ загружать в GitHub.
В репозитории хранится только `.env.example`.

## Первый запуск

Python 3.10+.

```bash
pip install -r requirements.txt
```

Создайте файл `.env` рядом с `bot.py`:

```env
MAX_BOT_TOKEN=ваш_токен_MAX
```

Запуск:

```bash
python bot.py
```

Для первого теста используется Long Polling. MAX разрешает его для разработки и тестирования; для production позже переведём бота на HTTPS Webhook.
